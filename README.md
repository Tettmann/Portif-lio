## 🧭 Sobre

Sou desenvolvedor com conhecimento em JavaScript, Python, C# e MySQL, atualmente em transição para full stack, com foco também em inteligência artificial. Este site reúne minhas especialidades, um pouco sobre minha trajetória, os projetos que já desenvolvi e os certificados conquistados até aqui.

## ✨ Funcionalidades

- **Header fixo animado** — o menu de navegação se transforma em uma barra flutuante ao rolar a página.
- **Menu mobile** — navegação lateral responsiva com botão hambúrguer.
- **Fundo de partículas interativo** (particles.js) na seção inicial, com efeito de "grab" ao passar o mouse e "push" ao clicar.
- **Cards com efeito 3D** — nas seções de especialidades e certificados, os cards reagem ao movimento do mouse (tilt + sombra neon).
- **Filtro de projetos** — botões para filtrar projetos por categoria (Dados, Sistema, Site).
- **Cards de projeto com preview e overlay** — hover com zoom, brilho neon e título do projeto.
- **Totalmente responsivo** — layout adaptado para desktop, tablet e mobile.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura semântica das páginas
- **CSS3** — estilização, Flexbox, Grid, animações e media queries
- **JavaScript** — interatividade (menu, filtros, efeitos de hover, scroll)
- **[particles.js](https://vincentgarreau.com/particles.js/)** — animação de partículas do topo do site
- **Bootstrap Icons** — ícones utilizados no header e footer
- **Google Fonts** — fonte Montserrat

## 🚀 Como rodar localmente

Este é um site estático, não precisa de instalação ou build.

1. Clone o repositório:
   ```bash
   git clone https://github.com/Tettmann/<nome-do-repositorio>.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd <nome-do-repositorio>
   ```
3. Abra o arquivo `index.html` no navegador (ou use a extensão **Live Server** no VS Code).
